# Amit Tandon — Common Sense, Under Review

Final website build (not a throwaway HTML preview).

## Concept

**Common Sense, Under Review** — observational Hindi stand-up homepage with live tickets for *Aise Kaise*.

## Run locally

```bash
npm install
npm run dev
```

Then open the local address Vite prints (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

Output lands in `dist/`.

## Git

This folder is a Git repository. Commits are made only when you ask for them.

## Layout

- `src/` — page code, styles, section modules
- `data/` — shows, material, site facts
- `public/images/` — web-ready locked images
- `assets/` — originals and candidates
- `docs/` — creative lock, plan, archived previews
